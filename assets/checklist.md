# 分析检查清单

## 开始前

- [ ] 文本类型是论述、对话、转述、虚构、广告还是片段？
- [ ] 哪些是作者原话，哪些是引用或分析者重建？
- [ ] 用户要求的是 quick、full、debate 还是 teaching？
- [ ] 是否需要外部事实核验？如果不需要，是否已声明边界？

## 论证重建

- [ ] 找到最终结论，而不是把理由当结论。
- [ ] 列出显式前提。
- [ ] 只补充结论真正需要的隐含前提，并标记为重建。
- [ ] 写出推理类型。
- [ ] 试过最善意、最合理的解释。
- [ ] 没有把口语夸张自动当成严格全称量词。

## 评估

- [ ] 形式层：若为演绎，检查条件和量词。
- [ ] 证据层：样本、相关性、因果、统计和替代解释是否足够？
- [ ] 辩证层：举证责任、公平回应和可反驳条件是否合理？
- [ ] 修辞层：语言是否替代了理由，而不是只让语气变强？
- [ ] 事实真伪与论证有效性已分开。

## 匹配目录

- [ ] 先用普通语言说清断点，再选标签。
- [ ] 使用最具体的条目，而不是最多条目。
- [ ] 同一推理断点没有重复计算。
- [ ] 每条都有原文证据。
- [ ] 已标注 `确认 / 较可能 / 语境相关 / 不构成谬误`。
- [ ] 已给置信度及理由。

## 误报复核

- [ ] 身份、经验、权威、情绪和传统是否可能与本议题相关？
- [ ] 是否忽略了作者的限定、证据或后续澄清？
- [ ] 是否把弱概括扩写成强主张？
- [ ] 是否把认知偏差直接当成谬误？
- [ ] 是否用“存在谬误”推出“结论为假”？
- [ ] 是否给发言者强加了未证实的动机或人格？

## 输出

- [ ] 有结论摘要、论证地图、关键问题、反向检验、改写建议和边界说明。
- [ ] 每个问题包含机制、影响、边界和修复条件。
- [ ] 改写没有冒充作者立场。
- [ ] 语言中性、可复核、没有嘲讽。
