# 论证重建

论证重建是把自然语言整理成可评估结构。它既不能照抄句子，也不能替作者发明观点。

## 1. 图尔敏结构

复杂现实论证可用六部分表示：

| 部分 | 问题 |
|---|---|
| Claim 主张 | 想证明什么？ |
| Grounds 依据 | 提供了哪些事实或材料？ |
| Warrant 保证 | 依据为什么能支持主张？ |
| Backing 支持 | 保证本身靠什么成立？ |
| Qualifier 限定 | 结论有多强、适用到哪里？ |
| Rebuttal 例外 | 哪些情况会推翻或削弱结论？ |

自然语言常省略 Warrant 和 Qualifier。分析者的任务是找出它们，而不是把所有省略都判为谬误。

## 2. 隐含前提的最小化原则

用“缺口测试”：

1. 暂时假设显式前提都为真。
2. 问还缺哪一条最弱、最一般且必要的假设，才能使结论跟随。
3. 加入后再次测试。
4. 直到结论可推出，或确认不存在合理补充。

例子：

```text
P1：三名员工离职。
C：现在的年轻人都吃不了苦。
```

需要的隐含前提包括：

```text
A1：这三名员工能代表“现在的年轻人”总体。
A2：离职主要因为不能吃苦，而不是岗位、薪酬、管理等原因。
A3：“吃不了苦”有可用标准。
```

这些前提不是作者原话，必须标记为重建。

## 3. 多重重建

有些句子可合理理解为两个论证：

```text
解读 A（较弱、更可支持）：
  这三位员工可能不适应这里的工作强度。

解读 B（较强、作者表面表达）：
  所有现在的年轻人都不能承受工作压力。
```

优先分析文本实际支持的最强合理解读，同时说明如果作者只主张较弱版本，结论会如何改变。

## 4. 条件句与因果句

### 条件句

```text
如果 P，那么 Q。
```

不能自动推出：

```text
Q，所以 P。
非 P，所以非 Q。
```

但自然语言里的“如果”可能是因果、定义、承诺或建议，不要机械套公式。

### 因果句

把因果主张拆成：

```text
原因候选 X
结果 Y
机制 M
对照/比较组 C
排除的替代解释 E
```

缺少任何部分通常意味着证据不足，而不是立即构成某个专名谬误。

## 5. 规范论证

规范结论至少需要：

- 一个事实前提；
- 一个价值或规范前提；
- 一个连接两者的政策原则。

例：

```text
P1：这项政策会降低事故率。
V1：降低事故率优先于相关成本。
C：我们应该实施这项政策。
```

如果 V1 被省略，分析者可以指出价值前提未明示，但不能自动说事实前提错误。

## 6. 对话中的论证

对话需要增加：

- 说话者回应的是哪一问；
- 引用“你刚才说”是否准确；
- 各方是否接受同一词义；
- 谁提出主张；
- 谁已提供证据；
- 是否在回答另一个更弱的问题。

分析时分别标记：

```text
A 的主张
B 对 A 的复述
B 的反驳
A 的回应
```

不要自动把 B 的复述当作 A 的原始立场。

## 7. 隐含前提的合法性

可接受补充：

- 逻辑连接；
- 文本暗示；
- 领域内普遍定义；
- 使论证不自我矛盾的弱假设。

不可接受补充：

- 作者明确否认的内容；
- 需要全新经验证据的强主张；
- 为了替作者赢而加入的争议前提；
- 为制造谬误而加入的极端前提。

## 8. 重建记录

在报告中保留：

- 显式前提；
- 重建前提；
- 重建依据；
- 对结论强度的影响。

让读者能区分“作者说了”与“分析者为了理解而补上”。
