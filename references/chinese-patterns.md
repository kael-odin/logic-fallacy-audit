# 中文话术与逻辑模式

以下是中文语境中常见的表达线索。它们只提示可能的结构，不构成自动判定。必须结合完整对话和实际论证。

| 表达 | 可能机制 | 何时不是谬误 |
|---|---|---|
| “大家都这么说” | 诉诸流行、从众偏差 | 多数意见被当作调查证据，且有代表性的数据支持 |
| “那么多人还能都错？” | 诉诸流行、虚假共识 | 讨论的确实是群体偏好或集体选择 |
| “你行你上” | 人身攻击、资格转移 | 议题确实要求亲历操作能力，且经验与判断直接相关 |
| “你又不是这个专业的” | 人身攻击、权威门槛 | 专业训练是判断特定技术问题的必要条件 |
| “我当年比这苦多了” | 相对剥夺、诉诸艰苦经验 | 只用于个人经历对照，没有据此否定他人的全部困难 |
| “那咋了 / 所以呢” | 轻蔑式转移、对话责任回避 | 对方确实没有说明问题为何影响结论 |
| “我只是提出疑问” | JAQing off、海狮式追问 | 是真的一次性澄清，且接受回答并继续论证 |
| “你急了” | 语气打压、转移话题 | 情绪确实导致论证中断，但仍需回应内容 |
| “一个巴掌拍不响” | 因果过度简化、公正世界假设 | 用于说明冲突存在双向互动，而非据此平均分配责任 |
| “苍蝇不叮无缝蛋” | 公正世界假设、受害者归因 | 只作为俗语引用，没有从结果反推当事人有错 |
| “别人都行，为什么你不行” | 诉诸流行、错误比较 | 岗位标准和外部条件相同，且已有可比证据 |
| “不转不是中国人” | 忠诚绑架、威胁、虚假两难 | 基本不构成逻辑支持，属于身份压力 |
| “存在即合理” | 概念歧义、现状偏好 | “合理”被明确解释为“有形成原因”，不是“应该保留” |
| “专家都说了” | 诉诸权威 | 专家与议题直接相关，来源可查，意见有共识和方法支撑 |
| “科学研究表明” | 无来源权威、模糊引用 | 给出可核验研究、样本与适用范围 |
| “你自己不也……” | 诉诸虚伪、转移话题 | 讨论目标是同一标准是否被一致执行，而非主张真值 |
| “如果今天允许 A，明天就会 B” | 滑坡谬误、恐惧诉求 | 每个中间步骤都有机制和证据，且概率没有被夸大 |
| “不是 A，就是 B” | 虚假两难 | 选项确实穷尽且互斥 |
| “这不就是 A 吗” | 框架替换、虚假等同 | A 是准确分类，且定义公开可检验 |
| “没有证据证明不是” | 诉诸无知、举证责任倒置 | 在严格无罪推定或监管标准中，举证责任规则另有规定 |
| “他以前也这样” | 诉诸虚伪、关联污染 | 用来评估行为模式，而非用过去行为替代当前命题证据 |
| “你先证明给我看” | 举证责任转移 | 对方确实提出肯定主张且负初始举证责任 |
| “我只是按常识说” | 常识权威、免证前提 | 常识命题可靠、可公开检验，且不需要专业数据 |
| “这是传统” | 诉诸传统 | 传统事实与议题相关，例如说明历史延续性 |
| “现在都什么年代了” | 诉诸新颖、时间压力 | 只表达时代变化，没有用“新”替代效果证据 |
| “别人更惨” | 相对剥夺、转移焦点 | 用于资源排序，且明确承认当前问题仍存在 |
| “你要感恩” | 道德转移、责任转移 | 感恩作为个人伦理话题，而非否定具体申诉的证据 |
| “开个玩笑而已” | 重新定义、责任回避 | 确实没有命题主张，或说话者立即澄清纠正 |
| “他都能成功，你也可以” | 幸存者偏差、错误类比 | 两人条件、路径和风险有可验证的相似性 |

## 使用规则

1. 先引用原句，再看其在前文中的实际功能。
2. 口语夸张不能自动当作“所有”的全称量词。
3. 反问、俗语和网络梗可能同时承担多个功能。
4. 如果短语没有参与结论推导，最多标为修辞或表达问题。
5. 中文称谓、礼貌和面子机制会影响交流，但不应被心理化。

## 高频映射与主判优先级

同一个短语可能同时命中多个条目。按实际断点选一个主标签；其余写入“相关但不主判”。

| 表达 | 优先候选 ID | 主判规则 |
|---|---|---|
| “我当年比这苦多了” | `relative-privation`；`anecdotal-evidence` | 用来压低当前困难时主判相对剥夺；只叙述个人经历时不构成谬误 |
| “大家都这么说” | `appeal-to-popularity`；`bandwagon-bias` | 用流行度证明真假时主判诉诸流行；偏差只在解释判断倾向时作背景 |
| “你行你上 / 你又没做过” | `ad-hominem-circumstantial` | 亲历不是议题必要条件时主判人身攻击；职位经验直接影响判断时可能合理 |
| “那你自己呢 / 那别人呢” | `tu-quoque` 或 `whataboutism` | 仍在原议题上指出双重标准用前者；换成另一个话题用后者 |
| “我只是提出疑问” | `jaqing-off` | 反复暗示结论却拒绝承担举证责任时使用；一次性澄清不判 |
| “不转不是自己人” | `appeal-to-loyalty`；`argumentum-ad-baculum` | 身份排斥为主判忠诚绑架；明确威胁惩罚为主判诉诸威胁 |
| “存在即合理” | `equivocation`；`appeal-to-status-quo` | 把“有原因”偷换成“应当保留”时主判偷换概念；直接维护现状时可用诉诸现状 |
| “没有证据证明不是” | `appeal-to-ignorance`；`burden-of-proof-reversal` | 用证据缺失证明存在时用前者；要求质疑者证明否定时用后者 |
| “连这都受不了，以后怎么可能成功” | `rhetorical-question-as-assertion`；`causal-oversimplification` | 反问只作劝勉时先标修辞；把单次压力直接绑定长期成功时主判因果过度简化 |
| “别人都可以，为什么你不行” | `appeal-to-popularity`；`false-equivalence` | 用他人行为证明要求合理时用前者；忽略条件和差异时用后者 |
| “你急了” | `tone-policing` | 只评论语气以回避内容时使用；情绪确实造成沟通中断时仍需回应实质 |
| “开个玩笑而已” | `definitional-retreat` | 原句实际承担指控、事后才改称玩笑且拒绝纠正时可判；立即澄清并不再使用时不判 |
