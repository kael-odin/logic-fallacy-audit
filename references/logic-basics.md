# 逻辑基础

本页只覆盖做文本分析所需的最小概念。术语是工具，不是给发言者贴的等级。

## 1. 论证

论证由理由和结论组成：

```text
前提 P1、P2 …
因此结论 C
```

只有断言、描述或口号，不一定是论证。没有明确理由时，可以分析预设和修辞，但不要强行套形式谬误。

## 2. 有效性、真与可靠性

- **有效性**：如果前提为真，结论是否必然为真。
- **前提真假**：现实内容是否正确。
- **可靠性**：论证有效且前提都真。

三者必须分开：

```text
论证有效 ≠ 结论真实
结论真实 ≠ 论证有效
前提虚假 ≠ 推理形式无效
```

非演绎论证通常不追求“必然有效”，而看证据支持强度。

## 3. 常见有效演绎形式

### 肯定前件

```text
P → Q
P
所以 Q
```

有效。

### 否定后件

```text
P → Q
非 Q
所以非 P
```

有效。

### 假言三段论

```text
P → Q
Q → R
所以 P → R
```

有效。

### 析取三段论

```text
P 或 Q
非 P
所以 Q
```

在“或”至少一个成立时有效。若是排他性或，需明确额外条件。

## 4. 条件方向

`P → Q` 表示：

- P 是 Q 的充分条件：P 足够使 Q 成立；
- Q 是 P 的必要条件：没有 Q 就没有 P；
- 不能推出 Q → P；
- 不能从非 P 推出非 Q。

例子：

```text
如果是哺乳动物，就一定不是只靠鳃呼吸的鱼。
```

不能因此说：“如果不是哺乳动物，就一定可以用鳃呼吸。”

## 5. 量词

- `所有 A 都是 B`：A 的全体落在 B 中。
- `有些 A 是 B`：至少一个 A 同时是 B。
- `没有 A 是 B`：A 与 B 没有交集。
- `并非所有 A 都是 B`：至少一个 A 不是 B。

注意：

```text
并非所有 A 都是 B ≠ 所有 A 都不是 B
```

量词顺序也可能改变含义：

```text
每个人都有一个方法
≠
存在一个方法适合每个人
```

## 6. 三段论词项

传统三段论有三个词项：

- 大项：结论谓项；
- 小项：结论主项；
- 中项：连接两个前提。

检查：

- 词项是否保持同一含义；
- 中项是否至少在一个前提中覆盖全体；
- 结论是否把词项范围扩大；
- 前提是否偷偷引入存在性。

## 7. 归纳强度

归纳结论通常带有概率和范围。评估看：

- 样本大小；
- 抽样代表性；
- 数据来源；
- 反例比例；
- 是否有机制支持；
- 结论强度是否超过数据。

```text
这三个样本支持一个暂定假设
≠
所有人都是这样
```

## 8. 因果

因果主张至少可拆为：

- 原因候选；
- 结果；
- 机制；
- 时序；
- 对照或反事实；
- 替代解释。

相关可以来自：

- A 导致 B；
- B 导致 A；
- C 同时导致 A 和 B；
- 选择机制使 A、B 共同出现；
- 偶然。

无法完全排除所有混杂，不表示因果为零；重点是比较证据总量。

## 9. 概率

条件概率 `P(A|B)` 表示在 B 条件下 A 的概率，不等于 `P(B|A)`。

认真检查：

- 基准率；
- 分母；
- 假阳性、假阴性；
- 样本选择；
- 多重比较；
- 效应量；
- 置信区间。

“统计显著”不等于“现实重要”，“不显著”也不等于“没有效应”。

## 10. 规范推理

从事实到“应该”通常需要价值前提：

```text
P1：X 会产生结果 R。
V1：R 比其他后果更值得追求。
C：因此应该做 X。
```

省略 V1 不必然错误，但分析者应指出价值前提未明示。

## 11. 对话规则

分析对话时问：

- 谁提出新主张，谁承担初始举证责任？
- 回应是否针对对方最强版本？
- 是否允许对方提出反例？
- 新证据出现后，标准是否保持一致？
- 是否把不能证明否定当成肯定成立？

## 12. 最容易混淆的边界

- 谬误不是人格评价。
- 情绪化表达不是自动谬误。
- 权威引用不必然错误。
- 人身信息有时与可信度相关。
- 传统可以携带制度经验。
- 相关性可以支持因果假设。
- 类比可以提出假设和解释机制。
- 认知偏差不是论证形式。
- 识别谬误不能证明结论为假。
