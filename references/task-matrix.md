# 推理任务与分析路线

先判断任务，再选目录。形式谬误只适用于演绎，统计标签只适用于相应数据关系。

| 推理任务 | 首要问题 | 常用分类 | 必要证据 | 高频误判 |
|---|---|---|---|---|
| 演绎 | 前提真时结论是否必然真 | formal、ambiguity | 有效形式、词项稳定 | 把归纳概括当形式无效 |
| 归纳概括 | 样本能否支持总体结论 | causal、statistical | 样本代表性、基准率 | 小样本只提供线索却被当总体证明 |
| 因果 | A 是否实际导致 B | causal、statistical | 时序、机制、对照、替代解释 | 看到相关就要求绝对因果，或把相关直接当因果 |
| 统计 | 数字定义和不确定性是否正确 | statistical、causal | 分母、条件概率、效应量 | 统计显著当现实重要 |
| 解释 | 哪个假设最能解释证据 | explanation | 可检验预测、竞争解释 | 不可证伪解释被当唯一可能 |
| 定义 | 词义和分类是否稳定 | ambiguity | 明示定义、边界案例 | 词义自然变化被当偷换 |
| 规范 | 事实与价值如何连接 | normative | 明确价值前提 | 所有价值判断都被当谬误 |
| 政策 | 目标、效果、成本、替代方案 | normative、causal、statistical | 效果比较、分配、副作用 | 只谈收益或只谈风险 |
| 对 dialogue | 谁回应了什么、谁举证 | presumption、relevance | 原话、回应链、责任规则 | 把未回应当承认 |
| 说服传播 | 语言是否替代证据 | rhetorical、relevance | 去除修辞后的论证 | 把所有修辞都当操纵 |

## 路线 1：演绎

1. 将自然语言翻译成条件、析取、合取和量词。
2. 检查条件方向。
3. 检查量词次序和否定辖域。
4. 检查词项是否保持同一含义。
5. 只在形式无效时使用 formal 标签。

## 路线 2：归纳与样本

1. 明确样本和总体。
2. 检查样本大小、选择方式和时间范围。
3. 比较结论强度与数据强度。
4. 寻找失败样本和幸存者偏差。
5. 将结论收窄到数据允许的范围。

## 路线 3：因果

1. 列出原因候选和结果。
2. 检查时序。
3. 建立机制。
4. 比较共同原因、反向因果和选择偏差。
5. 评估对照、剂量反应和可重复性。

## 路线 4：统计

1. 找分母和总体。
2. 写清条件概率。
3. 找基准率。
4. 检查样本和比较次数。
5. 区分显著、效应量和现实影响。
6. 检查平均值之外的分布。

## 路线 5：解释

1. 列出需要解释的现象。
2. 至少提出两个竞争解释。
3. 比较解释力、简洁性和可检验预测。
4. 检查反证是否被无成本吸收。
5. 说明哪种结果会降低信念。

## 路线 6：规范与政策

1. 分开事实前提与价值前提。
2. 明确目标和受益者、成本承担者。
3. 比较现状、方案和替代方案。
4. 检查副作用、可逆性和不确定性。
5. 不把“不完美”直接等同于“没有价值”。

## 路线 7：对话与修辞

1. 标记各方原话和回应对象。
2. 检查举证责任和公平机会。
3. 找稻草人、转移话题、无限追问或目标移动。
4. 去掉情绪、身份和口号，检查剩余论证。
5. 只有在修辞替代了证据或阻碍了讨论时，才升级为实质问题。
