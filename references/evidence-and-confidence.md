# 证据与置信度

逻辑报告必须诚实表达不确定性。置信度不是语气强弱，而是当前证据对判断的支持程度。

## 1. 证据标签

每个关键判断可归属于：

| 标签 | 含义 |
|---|---|
| `原文直接` | 引用句明确显示结构 |
| `结构必需` | 为使论证连贯而重建的前提 |
| `语境推断` | 依赖文本外背景或对话历史 |
| `外部核验` | 使用用户提供或另行查证的来源 |

只有 `原文直接` 通常足以支持 `确认 + 高置信度`。

## 2. 置信度标准

### 高

- 原句完整；
- 结论和支持关系明确；
- 竞争性善意解释很弱；
- 谬误条目与实际结构直接对应；
- 不需要外部事实即可看出推理断点。

### 中

- 文本结构清楚，但缺一到两个关键背景；
- 存在某种合理替代解读；
- 谬误判断依赖作者是否真的持某立场；
- 结论强度或定义仍有歧义。

### 低

- 只有片段；
- 引号内是转述或虚构；
- 多义词无法确定；
- 缺少对话上下文；
- 分析对象可能只是修辞，不足以证明推理替代。

## 3. 提高置信度

- 找到完整论证段；
- 确认作者的限定词；
- 比较多个段落；
- 检查同一词是否前后一致；
- 找到作者自己给出的定义；
- 获得对话中被回应原话；
- 补充样本来源或统计口径。

## 4. 降低置信度

- 文本来自二次转述；
- 关键反例在省略部分；
- 作者已在前文给出证据；
- “所有人”其实是口语夸张且有范围限定；
- 权威身份与议题直接相关；
- 情绪表达伴随充分论证；
- 专业术语有领域定义。

## 5. 结论强度表

| 原文措辞 | 需要的典型支持 |
|---|---|
| “有些”“可能”“倾向于” | 有限样本或机制线索 |
| “多数”“通常” | 代表性数据、趋势或系统综述 |
| “一定”“必然” | 演绎有效或极强证据 |
| “导致” | 因果机制、时序、对照和替代解释排除 |
| “应该” | 事实前提 + 价值前提 + 政策比较 |

证据强度低于结论强度，就是需要指出的主要问题。

## 6. 不说“已证明”

以下表述需要来源和定义：

- 已证明；
- 科学共识；
- 数据表明；
- 专家一致认为；
- 所有人都知道；
- 研究表明。

如果没有来源，报告只写“文本声称”，不替作者补足权威。

## 7. 两种不确定性

### 认识不确定性

缺少事实或数据。

### 解释不确定性

有多种都说得通的论证重建。

报告应分别说明。不要用一句“信息不足”同时掩盖两类问题。

## 8. 衡量影响

每个发现还要判断：

- 它支持哪个结论；
- 主结论是否依赖它；
- 是否有其他独立理由；
- 修复它需要多少证据；
- 不修复时结论应缩到什么范围。

高置信度的小问题，不等于主结论被推翻。
