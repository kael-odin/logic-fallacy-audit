| 发现 | 影响 | 修复 |
|---|---|---|
| `contextomy` 与 `quote-mining` 是同一机制 | 中 | 合并为 `quote-mining`，补齐语境剥离别名 |
| 缺少多个常见谬误 | 中 | 新增 20 个高价值条目 |
| 别名可能与其他条目 ID 或主名冲突 | 中 | 增加全局别名冲突校验 |
| 缺少 `id` 时校验器可能崩溃 | 高 | 改为安全读取并返回 `missing-id` |
| 旧生成文件不会被发现 | 中 | 增加残留检测与自动清理 |
| 分类编号依赖硬编码映射 | 低 | 改为按 `categories.toml` 顺序生成 |
| 完整仓库校验在缺 ID 时仍可能进入生成器 | 高 | 仅在目录无错误时检查生成文件 |
| 非法字段与评测值类型可能触发异常 | 高 | 安全读取字段并分项报告类型错误 |
| 全角字符和多余空白可能绕过别名冲突 | 中 | 统一使用 NFKC、trim 和 casefold 规范化 |
| `contextomy` 合并后的跨语境边界不完整 | 低 | 补足语境问题和边界说明 |
