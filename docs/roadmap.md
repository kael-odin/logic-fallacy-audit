# Roadmap

## v2.0 — 解说模式与知识覆盖审计

状态：当前版本，已实现。

- 新增 `explainer` 模式、专用模板、完整样例、专项 rubric 和两条回归样本。
- 固定“原话 → 表面主张 → 隐藏前提 → 断点 → 最小反例 → 边界 → 修复”的七拍结构。
- Explainer 复用 Full 的原文、置信度、影响、边界和修复字段，不允许为了节奏降低证据标准。
- 目录从 250 条扩展到 260 条，补充十项有独立机制的标准名称与近期修辞模式。
- 新增自动生成的知识覆盖审计，检查全部 260 条的定义、推理式、诊断问题、例子、边界、混淆项、关联项和别名。
- 扩写用户指定的十类核心谬误，加入结构测试、最小反例、合理边界与报告句式。
- 统一 Skill、Citation、Changelog 与公开版本为 `2.0.0`。

## v1.5 — 评测运营

状态：已实现；真实模型覆盖仍是后续运营项。

- 记录不同模型、日期与提示词版本下的评测结果和失败模式。
- 已增加政策论证、统计数据和长对话专项 rubric。
- 已建立误报回归看板，区分已修复、仍存在、已失效和边界变化。
- 已建立模型运行账本、fixture 基线和模型运行看板。
- 已扩展 Teaching 的练习生成、难度分层与答案一致性评测。
- 已补齐反讽转述与多论证单元评测样本。
- 尚未替用户伪造真实模型成绩；当前账本明确显示真实模型案例数为 0。

## v1.4 — 教学与可视化

状态：已实现。

- 从 Markdown 报告生成 Mermaid 论证图。
- 生成问题关系图和修复前后对照图。
- 增加教学模式、难度层级与答案一致性规范。
- 增加 10 道带答案的课堂练习。
- 增加 6 组中文逻辑写作改写示例。
- 增加完整教学报告样例与 CI 门禁。

## v1.3 — 输入工作流与双语报告

状态：已实现。

- 新增 10 个高价值谬误与论证模式。
- 目录扩展到 250 条：218 条谬误/论证模式，32 条认知偏差。
- 行为评测扩展到 43 条，新增条目均有回归样本。
- 对公开常见谬误清单进行第二轮差距扫描，并保留未达门槛候选。
- 增加源文本候选块、SHA-256、行号与精确引文定位。
- 增加长文本、字幕与网页清洗边界规范。
- 增加报告 `[Lx-Ly]` 引用核验。
- 增加英文报告模板、英文样例与中英术语表。
- 报告校验器同时接受中文和英文固定字段。

## v1.2 — 报告验收与评测强化

状态：已实现。

- 增加 Markdown 报告结构校验器。
- Full / Debate 报告校验引用、判定、置信度、影响、边界、替代解释和修复条件。
- Quick 报告校验核心章节、引用、标签和置信度。
- 增加 `lint-report` CLI 与 CI 样例报告门禁。
- 行为评测扩展到 33 条，覆盖四种模式、中英混杂、长文对话和负样本。

## v1.1 — 覆盖与校验强化

状态：已实现。

- 可安装 Skill。
- 10 类、240 条结构化知识与相邻偏差。
- 完成常见谬误外部清单差距扫描。
- 合并重复概念并补充 20 个高价值条目。
- 增加别名冲突、缺失 ID、空分类和残留生成文件检查。
- Quick / Full / Debate / Teaching 模式。
- 误报防线与置信度规范。
- 报告模板、中文语料指南和完整示例。
- CLI、生成器、测试、CI。

## 暂不计划

- 自动给个人打“逻辑可信度”分。
- 根据文本诊断心理疾病、政治人格或恶意。
- 未经授权批量抓取视频字幕。
- 宣称覆盖所有哲学传统中的全部谬误。
